# AUDIT 3 — Audio dock a tutta larghezza (2026-11-25, dsVersion 0.5.0)

## 1. Cosa è cambiato
L'audio non è più nella sidebar né in una scheda: è un **dock inferiore a tutta viewport**, collassabile, presente in ogni schermata dell'editor.

- **Collapsed (56px):** Audio + badge REACTIVE + file, tempo `00:01:00`, `82 BPM`, stop, play, **Upload audio**, volume, MIDI, chevron di espansione.
- **Expanded (322px):** tab Presets/Scenes, waveform a tutta larghezza (140 barre, playhead, porzione riprodotta in `selection`), tabella modulazioni: `PRESET · REACT TO · SOURCE · SENSITIVITY · RANGE · FREQUENCY` con 2 preset, rimozione per riga e `+ Add preset`.
- La sidebar torna a essere **solo Scene** (gruppi + Glyph presets + Save).
- `Organism/AudioPanel` (pannello laterale) **rimosso**: una sola fonte per l'audio (C5 deprecazione).

## 3. Accessibilità

| Requisito | Esito |
|---|---|
| Contrasto | testo `foreground` 17.2:1 su `card`; label `muted-foreground` 7.1:1; badge selection-solid + selection-foreground 5.7:1 |
| Target | IconButton 32×32, select 26px, slider 26px, tab 28px (≥24) |
| Non solo colore | stato REACTIVE = badge testuale; preset attivo = pill + label |
| Focus | i controlli usano i master con `State=Focus` (ring 2px) |
| Ordine focus | Audio → file → tempo → BPM → stop → play → upload → volume → MIDI → expand → (expanded) tabs → waveform → preset rows |
| Riduzione motion | la waveform è statica; nel codice segue `respectReducedMotion` |
| Semantica | il dock è una `region` con label "Audio"; le righe preset sono una tabella con header |

## 5. Stati aggiunti (chiusura B7)

Il dock ha ora **due assi indipendenti**: `State` (Collapsed / Expanded) × `Audio` (Ready / Idle / Error) — 6 varianti.

| Variante | Cosa mostra |
|---|---|
| Collapsed · Ready | comandi principali, trasporto attivo, upload, volume, MIDI, espansione |
| Collapsed · Idle | badge `NO FILE`, "No audio loaded", tempo `—:—`, trasporto disabilitato, CTA Upload |
| Collapsed · Error | badge `ERROR`, "could not decode", trasporto disabilitato, **Retry upload** |
| Expanded · Ready | tabs, waveform con playhead, tabella preset attiva, `+ Add preset` |
| Expanded · Idle | waveform piatta, messaggio "Load an audio file to add modulation presets" + Upload |
| Expanded · Error | waveform piatta `destructive`, messaggio d'errore + "Choose another file", preset e Add preset nascosti |

`Organism/WaveformWide` ha gli stessi tre stati (Playing / Idle / Error).
Schermata: `Screen/Editor State=Audio error` (Content 678 + dock 222 = 900); `State=Empty` usa il dock Idle.

## 6. Aperti residui
- `Scenes` è presente come tab ma senza contenuto: serve una decisione di prodotto.
- Volume e sensitività non hanno tooltip con il valore esatto (dB/%).
- Il dock non è ridimensionabile a mano (solo collapsed/expanded): scelta deliberata, da confermare.
